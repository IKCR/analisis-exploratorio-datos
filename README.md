# Análisis exploratorio: Educación preescolar, básica y media en Colombia

Proyecto del Grupo 1. 
Análisis exploratorio de la población en edad escolar (5 a 16 años) y sus indicadores educativos por municipio, con datos del Portal Nacional de Datos Abiertos de Colombia.


## Conjunto de datos

- **Nombre:** MEN_ESTADISTICAS_EN_EDUCACION_EN_PREESCOLAR, BÁSICA Y MEDIA_POR_MUNICIPIO
- **Entidad:** Ministerio de Educación Nacional
- **Periodo:** 2011–2024
- **Registros:** aproximadamente 15.700
- **Variables:** 41
- **URL:** https://www.datos.gov.co/Educaci-n/MEN_ESTADISTICAS_EN_EDUCACION_EN_PREESCOLAR-B-SICA/nudc-7mev
